# Governance

InferTap maintains this project. The lead maintainer listed in [MAINTAINERS.md](MAINTAINERS.md)
has final responsibility for scope, design decisions, and releases.

## Changes and decisions

Submit changes through pull requests under the [contribution guidelines](CONTRIBUTING.md).
A maintainer reviews each change. Propose substantial design changes in an issue before
implementation; describe the problem, alternatives, and compatibility impact.
Record accepted technical decisions in contributor documentation where they help future
maintenance.

Changes to the record contract belong in
[inference-events](https://github.com/infertap/inference-events). Land those changes
upstream before updating this repository's pin. Do not edit vendored conformance fixtures.

Raise disagreements in the relevant issue or pull request. The lead maintainer resolves
unsettled decisions and records the outcome there.

## Maintainers

An existing maintainer may nominate a contributor who demonstrates sustained technical
contributions and effective review. The lead maintainer confirms appointments and updates
the maintainer list.

Changes to this policy require a reviewed pull request.
